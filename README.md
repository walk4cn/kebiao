# 课表总览（多班级）

给大学辅导员用的「一张时间表看多个班级课表」工具。网页版零依赖、双击即用；另有可安装的 Android APK，方便手机随时查看。

内置 6 个班（城规 3231/3232、造价 3231/3232/3233/3234）共 80 条课，并固化了 1~11 节作息钟点。
（PDF 里其实有 32 个班 600 条课，想换别的班见下方「换一批班级怎么办」。）

## 一、电脑网页版

直接双击 **`index.html`** 即可打开使用（无需联网、无需安装）。

> 注意：`index.html` 与 `data.js` 需放在同一目录——内置课表数据在 `data.js` 里。只拷 `index.html` 一个文件会没有预置数据（可手动从 `课表数据.csv` 重新导入）。

功能：
- 多班级同屏总览，按教室配色（同教室同色、相邻教室明显不同）；设置里可切「按班级」配色。
- 单日视图（手机）/ 周网格（平板·电脑）自适应。
- 顶部可按周次筛选（支持单、双、1-6、9-13,15-16 等写法）。
- 顶部显示今天日期与「本学期第 N 周（单/双）」，可一键「回到本周」。
- 导入：设置里粘贴 CSV / Excel 课表与作息表；导出：生成 `.ics` 日历提醒，或导出 CSV。
- 数据存在浏览器 localStorage（key `kebiao.v1`），设置里有「重置为内置课表」。

> **周数怎么来的**：按「设置 / 导出」里的**学期第一周周一**推算，内置数据留空，需填一次（每人只填一次，存在本机）。
> 没填时顶部显示「周次未设置」并给出「设置开学日」按钮；开学前显示「还没开学」，超过默认周数显示「学期已结束」。

## 二、安卓 App（APK）

安装包：**`昌老师的课表.apk`**（自签名，桌面显示名「昌老师的课表」）。

安装提示：
- 首次安装需允许「未知来源」应用（设置 → 允许来自此浏览器的安装）。
- 系统可能弹出 Play Protect「已阻止安装」，点「仍安装」即可——这是自签名的正常提示，不是病毒。
- 已有旧版想升级：直接装新版会自动覆盖，无需卸载。

App 内导入/导出与网页版一致（导入走系统文件选择器，导出走系统文件保存）。

> 导入 CSV 时选「覆盖全部」只替换课程，**作息时间表会保留**；想和现有班级并存就选「追加」。
> 若选择器里文件全是灰的：本版已修复（不再按扩展名过滤），确认装的是 1.1 及以上。

### 换一批班级怎么办

PDF 里其实有 **32 个班、600 条课**，`data.js` 只是其中的一部分（`gen.py` 的班级白名单筛的）。
要换内置班级，不用改代码：

```bash
python extract.py [PDF路径]            # PDF -> parsed.json（含全部班级）
python gen.py data.js 课表数据.csv 班级1 班级2 ...   # 重新生成内置数据 + CSV 备份
python pick.py 输出.csv 班级1 班级2     # 只想要一份可导入的 CSV（不改内置数据）
```

例：`python gen.py data.js 课表数据.csv 城规1231 城规1232`
班级名写错会列出全部可用班级。CSV 表头为
`班级,星期,节次,课程,教室,教师,周次`（带 BOM，按星期+节次排序）。

## 三、目录结构

| 文件 | 说明 |
|------|------|
| `index.html` | 主程序（网页版入口） |
| `data.js` | 内置课表种子数据（`window.SEED`） |
| `课表数据.csv` | 内置 6 个班的课表 CSV 备份（与 `data.js` 同源） |
| `课表数据_城规造价323x.csv` | 城规3231/3232 + 造价3231-3234，共 80 条，供导入 |
| `extract.py` | 班级课表 PDF -> `parsed.json`（全部班级） |
| `pick.py` | 从 `parsed.json` 挑班，生成导入用 CSV |
| `gen.py` | 生成 `data.js`（含固化作息钟点，仅白名单班级） |
| `build-apk.sh` | 重新打包 Android APK |
| `android/` | Android 工程（WebView 壳） |
| `昌老师的课表.apk` | 安卓安装包（桌面显示名「昌老师的课表」） |

> 原始 PDF《班级课表 (光谷校区)8.30.pdf》未入库（已在 `.gitignore` 排除）。

## 四、修改后重新打包 APK

1. 改完 `index.html` / `data.js`；
2. 跑 `bash build-apk.sh`；
3. 产物覆盖回 `昌老师的课表.apk`（想改名：`APK_NAME=别的名字.apk bash build-apk.sh`）。

脚本会自动从 `android/` 同步工程到**无空格**的构建目录、必要时生成签名、构建并拷回 APK。

### 打包环境（一次性）

工具链装在 `~/.workbuddy-ai/binaries/android`（路径无空格）：

| 组件 | 版本 | 路径 |
|------|------|------|
| JDK | Temurin 17 | `.../android/jdk-17` |
| Android SDK | platform 36 + build-tools 36.0.0 | `.../android/sdk` |
| Gradle | 8.7 | `.../android/gradle-8.7` |
| 构建工程 | — | `~/.workbuddy/projects/kebiao-apk` |

换电脑时不必改脚本：用 `ANDROID_TOOLS` / `APK_PROJ` 两个环境变量即可覆盖默认路径。
依赖已缓存后可用 `KB_OFFLINE=1 bash build-apk.sh` 离线构建。

> 签名用 `kebiao.jks`（alias `kebiao`，密码 `kebiao2026`），已排除在 git 外，不会上传。
> **换电脑务必把 `kebiao.jks` 一起拷走**：签名不一致的话，旧版无法覆盖升级，用户得先卸载。
> 若确实只能用新生成的密钥，请改完构建后用
> `apksigner verify --print-certs 昌老师的课表.apk` 确认指纹，并在发布说明里提示用户先卸载旧版。
