# 课表总览（多班级）

给大学辅导员用的「一张时间表看多个班级课表」工具。网页版零依赖、双击即用；另有可安装的 Android APK，方便手机随时查看。

内置 8 个班（土木 3231/3232/3233/3234、土木 3241/3242、造价 3241/3242）的课表，并固化了 1~11 节作息钟点。

## 一、电脑网页版

直接双击 **`index.html`** 即可打开使用（无需联网、无需安装）。

> 注意：`index.html` 与 `data.js` 需放在同一目录——内置课表数据在 `data.js` 里。只拷 `index.html` 一个文件会没有预置数据（可手动从 `课表数据.csv` 重新导入）。

功能：
- 多班级同屏总览，按教室配色（同教室同色、相邻教室明显不同）；设置里可切「按班级」配色。
- 单日视图（手机）/ 周网格（平板·电脑）自适应。
- 顶部可按周次筛选（支持单、双、1-6、9-13,15-16 等写法）。
- 导入：设置里粘贴 CSV / Excel 课表与作息表；导出：生成 `.ics` 日历提醒，或导出 CSV。
- 数据存在浏览器 localStorage（key `kebiao.v1`），设置里有「重置为内置课表」。

## 二、安卓 App（APK）

安装包：**`课表.apk`**（自签名）。

安装提示：
- 首次安装需允许「未知来源」应用（设置 → 允许来自此浏览器的安装）。
- 系统可能弹出 Play Protect「已阻止安装」，点「仍安装」即可——这是自签名的正常提示，不是病毒。
- 已有旧版想升级：直接装新版会自动覆盖，无需卸载。

App 内导入/导出与网页版一致（导入走系统文件选择器，导出走系统文件保存）。

## 三、目录结构

| 文件 | 说明 |
|------|------|
| `index.html` | 主程序（网页版入口） |
| `data.js` | 内置课表种子数据（`window.SEED`） |
| `课表数据.csv` | 课表 CSV 备份，可重新导入 |
| `extract.py` | 从学校导出的班级课表 PDF 抽取数据 |
| `gen.py` | 生成 `data.js`（含固化作息钟点） |
| `build-apk.sh` | 重新打包 Android APK |
| `课表.apk` | 安卓安装包 |

## 四、修改后重新打包 APK

1. 改完 `index.html` / `data.js`；
2. 跑 `bash build-apk.sh`（Android 工程在 `C:\Users\Lenovo\.workbuddy\projects\kebiao-apk`，**路径不能有空格**）；
3. 产物覆盖回 `课表.apk`。

> 签名用 `kebiao.jks`（alias `kebiao`），已排除在 git 外，不会上传。
