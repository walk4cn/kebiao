**踩过的坑**：
1. `gradle.bat` / `keytool.exe` / `apksigner.bat` 是 Windows 程序，必须给 `C:\...` 路径；
   Git Bash 的 `/c/...` 会被当成无效目录（报 JAVA_HOME invalid / FileNotFoundException）。
   脚本里用 `cygpath -w` 转换导出给它们，bash 内部自检仍用 POSIX 路径。
2. `sdkmanager` 下载时进度不可见（`.temp` 里才看得到），容易误判成卡死——实际 dl.google.com 很快。
   国内没有可用的 Android SDK 镜像（腾讯 AndroidSDK 400、清华 404），无需切换；
   Maven 依赖走阿里云已在 build.gradle/settings.gradle 里配好。
3. 代理：环境有 `http_proxy=127.0.0.1:57075`，但实测直连 maven.aliyun.com / dl.google.com 都通，
   Gradle 不需要额外配代理。
4. 沙箱下 `find $HOME -maxdepth 4` 会因触碰 `.ssh` 被拒，搜索要限定目录。

1. 换密钥后 Gradle 的 up-to-date 判断不可靠（见过 `packageRelease UP-TO-DATE` 的情况），
