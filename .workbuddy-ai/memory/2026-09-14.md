## 页面顶部增加「今天 / 本学期当前周」显示

需求：在页面上显示当前周数和日期。

实现（`index.html`）：
- 顶栏新增一行 `#tbar`（`.tbar` 样式），位置在周次步进器那一行下面、星期条上面。
  内容：`今天 9月14日 周一 · 本学期第 3 周（单）`，右侧按需出现按钮。
- 新增函数：`termMonday()` / `todayWeek()` / `renderToday()` / `jumpToday()` / `setTerm()`。
- 周数按 `db.meta.termStart`（学期第一周周一）算：`floor((今天-起始周一)/7天)+1`。
- 状态分支：未填开学日→「周次未设置」+「设置开学日」按钮（跳到设置页并聚焦日期框）；
  开学前→「还没开学」；超过 `termWeeks`→「学期已结束」；正常→显示周数+单/双。
- 视图周 ≠ 本周时出现「回到本周」按钮，点击写入 `db.meta.week` 并落库。
- `render()` 里调用 `renderToday()`；`m_start/m_weeks/m_remind` 的 onchange 补了 `render()`，
  这样改完开学日顶部立刻更新。

注意：`data.js` 的 SEED 里 `termStart` 是空字符串，所以首次打开显示「周次未设置」。
需用户自己填学期第一周周一（推测 2026-08-31，但未擅自写入种子数据）。

## 决策：开学日不写进种子数据

曾提议把 `termStart` 默认设为 2026-08-31（按 PDF 文件名 8.30 推测），**用户选择「让用户手动设置就行」**，
故不写死。理由：填错会导致所有人周数全错，不如留空由用户自填。
相关事实（后续别踩）：
- `termStart` 的源头在 **`gen.py` 第 40 行**（`meta` 里硬编码 `termStart: ''`），
  `data.js` 是 gen.py 生成的（文件头标注"勿手改"）。要改必须两处一起改。
- 但 `parsed.json`（extract.py 的中间产物）已被 gitignore 且当前不存在，
  **gen.py 现在跑不了**，无法走"改源头→重新生成"的正常流程。
- 因此目前 `data.js` 里的 meta 仍是 `{week:1, termStart:'', termWeeks:20, remind:10}`。

README 已补充该功能说明与周数推算规则。
