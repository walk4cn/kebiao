## 修复：手机上导入文件时 CSV 全灰选不了

根因：`MainActivity.onShowFileChooser` 用 WebView 的 `p.createIntent()`，它把 HTML 的
`accept=".csv,.txt,.tsv"` **原样当 MIME 类型**传给系统文件选择器；`.csv` 不是合法 MIME
（应为 `text/csv`），选择器过滤后匹配不到任何文件 → 全部置灰。

修复：
- `MainActivity` 自己构造 Intent：`ACTION_GET_CONTENT` + `CATEGORY_OPENABLE` + `setType("*/*")`
  + `Intent.createChooser(..., "选择课表文件")`，不再按扩展名过滤（App 本来就按文本读）。
  失败时补了 `fileCb.onReceiveValue(null)` 避免回调挂死，并 Toast 提示。
- `index.html` 两处 file input 的 accept 改为合法 MIME：
  `text/csv,text/comma-separated-values,application/csv,text/plain,.csv,.txt,.tsv`。
- 版本 versionCode 1→2、versionName 1.0→1.1。

**踩坑**：Javadoc 注释里写了 `*/*`，其中的 `*/` 会提前闭合注释块，后面的中文被当代码解析，
javac 报「非法的类型开始 / 非法字符 '\uff0c'」。注释里绝不能出现 `*/`，改写成「任意文件」。

产物：课表.apk 40851 字节，签名仍为原密钥 7b5704d6…c19b，可直接覆盖升级。
验证：aapt2 dump badging 确认 versionCode=2/1.1；dex 内含新 Toast 文案；assets 含新 accept。
**用户已在真机验证：CSV 导入不再置灰，可以正常选文件导入。**（2026-09-14）
结论：自己构造 Intent + `setType("*/*")` 的方案在真机有效，后续同类问题照此处理。
